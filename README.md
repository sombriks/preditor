# [preditor][repo]

[repo]: https://github.com/sombriks/preditor

Pre tag editor

Inspired by [rexpaint][rexpaint]

[rexpaint]: https://www.gridsagegames.com/rexpaint/

Designed using [the monospace web][the-monospace-web]

[the-monospace-web]: https://owickstrom.github.io/the-monospace-web/

Written in javascript + [vue][vue]

[vue]: https://vuejs.org/

Bundled with [parceljs][parceljs]

[parceljs]: https://parceljs.org/
